Smarter organising (optional)

Paste a Claude API key from console.anthropic.com to let Claude file notes and answer questions like “what did I promise Sarah?”. The key is stored only in this browser, and notes are sent to Anthropic only when it's set.

Reminders

Tasks and events with a date remind you automatically: at the time you said, 30 minutes before an event, or at 9:00 if you gave no time. You can change it on any note.
